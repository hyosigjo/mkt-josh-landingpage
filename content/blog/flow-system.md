## 🔄 사용자 플로우(전환 퍼널) 관점 보강

이커머스 사이트는 단순한 페이지 집합이 아니라, 사용자의 구매 여정을 고려해 설계되어야 합니다. 따라서 **플로우 중심 사고**가 중요합니다.

### 📌 1. 기본 퍼널 단계 (AIDA 기반 변형)

| 단계  | 행동  | 대표 페이지/기능 |
| --- | --- | --- |
| **1\. 도달 (Awareness)** | 유입 (광고, 검색, SNS, 이메일 등) | 랜딩 페이지, 이벤트 페이지 |
| **2\. 탐색 (Interest)** | 카테고리 탐색, 상품 조회 | 카테고리 페이지, 검색, 필터 |
| **3\. 비교/의사결정 (Desire)** | 상세정보 확인, 리뷰 탐색 | PDP, Q&A, 리뷰, 추천 상품 |
| **4\. 구매 (Action)** | 장바구니 담기, 결제 | 장바구니, 주문/결제 페이지 |
| **5\. 후행 (Retention)** | 재방문, 리뷰 작성, CS | 마이페이지, 리뷰, 적립금, 이메일 |

각 플로우 단계에서의 **이탈률 분석** 및 **전환율 개선 지점 도출**이 마케터/PM의 주요 업무입니다.

### 🔍 실전 예시

-   PDP 페이지 체류 시간이 길지만 전환이 낮다 → 구매 버튼 위치/배송비 정보 등 UI/UX 개선 필요
-   장바구니 담기 비율은 높지만 결제 전환이 낮다 → 로그인 장벽, 결제 수단 부족 가능성 검토

## 🧩 시스템 구조 관점 보강

이커머스는 다양한 **백엔드 시스템**의 유기적 연동으로 구성됩니다. 이를 이해하면 마케터/운영자로서 **데이터 활용**과 **서비스 기획**에 훨씬 유리한 입장을 가질 수 있습니다.

### 📦 1. 시스템 구성도 (간단한 역할 요약)

| 시스템 | 설명  | 예시  |
| --- | --- | --- |
| **CMS (Content Management System)** | 배너, 기획전, 상품 설명 등을 관리 | Shopify Admin, Cafe24 |
| **PMS (Product Management System)** | 상품 등록, 옵션/재고 관리 | 마켓플러스, 고도몰 |
| **OMS (Order Management System)** | 주문/배송 정보 관리 | 이셀러스, 샵링커 |
| **WMS (Warehouse Management System)** | 물류창고와 연동, 출고 상태 | 로지스팟, 센터플러스 |
| **CRM (Customer Relationship Management)** | 고객 행동 기반 메시지/혜택 관리 | 샵페이, 카페24 CRM |
| **CDP (Customer Data Platform)** | 고객 데이터 수집/세분화/리타겟팅 | Treasure Data, Airbridge |

> ☑️ *CDP와 CRM은 유사하지만 CDP는 ‘행동 데이터 중심’, CRM은 ‘회원 데이터 중심’의 차이가 있습니다.*

## 🔧 사용자 플로우와 시스템 연계 매핑

| 사용자 단계 | 관여하는 시스템 | 비고  |
| --- | --- | --- |
| 광고 클릭 → 랜딩 도달 | CDP, CRM | 퍼널 진입 시점 추적 |
| 탐색 중 필터 사용 | CMS, PMS | 필터 기준은 PMS 데이터 |
| 장바구니 담기 → 결제 | OMS, PG | 쿠폰 발급은 CRM, 결제는 PG사 연동 |
| 주문 완료 → 배송 조회 | OMS, WMS | 실시간 송장번호 연동 |
| 재구매 유도 | CDP, CRM | 이전 구매 기반 리타겟팅 |

이러한 연결 구조는 마케터가 단순 이벤트 세팅을 넘어서, **유저의 맥락에 맞는 액션**을 기획하는 데 필수적인 배경지식입니다.

## 🧠 실무 중심 팁: Funnel Metric Tracking

-   **각 퍼널 구간의 전환율 계산**은 CDP 혹은 GA4 이벤트 기준으로 설정
-   **예시 지표 구성**:
    -   유입 대비 PDP 도달율
    -   PDP 대비 장바구니 전환율
    -   장바구니 대비 결제율
    -   결제 대비 재구매율
