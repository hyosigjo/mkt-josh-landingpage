# 블로그 분류와 제목 규칙

새 글을 쓰거나 제목을 고칠 때 참고하는 기준입니다. 분류는 글마다 **하나만** 정해서 `tags`에 적습니다(`content/tags.json`의 키). 분류 순서와 이름도 이 파일 기준으로 사이트에 표시됩니다.

## 분류

| 키 | 이름 | 어떤 글 |
| --- | --- | --- |
| `marketing` | 마케팅 | 실무에서 쓰는 마케팅 지식·방법론·사례·툴 리뷰 |
| `career` | 커리어 | 마케터 취업, 포트폴리오, 커리어 고민과 조언 |
| `insight` | 조쉬의 생각 | 일과 마케팅에 대한 짧은 생각 글 |
| `retrospective` | 회고 | 월간·분기·활동 단위로 돌아보는 글 |
| `field-notes` | 현장 기록 | 커피챗, 컨퍼런스, 행사·방문 후기 |
| `books` | 책 읽기 | 책 리뷰, 월간 독서 기록 |
| `favorite_things` | 좋아하는 것들 | 좋아하는 작품과 취미에서 얻은 생각 |

## 제목 규칙

**공통**
- 제목만 읽어도 무슨 글인지 알 수 있게 씁니다. 번호(`25-3`)나 날짜 코드(`250606`)만으로 시작하지 않습니다.
- 회사·서비스 이름을 `[Indent]`, `[브이리뷰]`처럼 대괄호 접두어로 붙이지 않습니다. 필요하면 본문에서 밝힙니다.
- `- 조쉬의 책 읽기`처럼 분류를 되풀이하는 꼬리말을 붙이지 않습니다. 분류는 사이트가 따로 보여줍니다.
- 이모지와 `:)` 같은 이모티콘은 제목에 넣지 않습니다. 본문에서는 자유롭게 써도 됩니다.
- 제목 끝에 마침표를 찍지 않습니다. 물음표·느낌표는 괜찮습니다.
- "주제: 핵심 메시지"처럼 두 부분으로 나눌 때는 **콜론(`: `)** 하나로 통일합니다. 썸네일에서는 콜론 앞이 작은 글씨로, 뒤가 큰 제목으로 들어갑니다.

**분류별 형식**

| 분류 | 형식 | 예시 |
| --- | --- | --- |
| 마케팅·커리어 | 자연스러운 한 문장 (질문형·방법형) | 알아서 면접 제안 받는 마케터 포트폴리오 만들기 |
| 연재 | `연재 이름 ①: 이번 편 주제` | 이커머스 스터디 ③: 이커머스 KPI 이해하기 |
| 조쉬의 생각 | 생각을 담은 한 문장. 짧아서 뜻이 모호하면 `: 부연` | 영웅은 이렇게 일한다: 시스템을 대하는 자세의 차이 |
| 회고 | `YY년 M월 회고: 핵심 메시지` (분기·반기도 같은 방식) | 23년 9월 회고: 나만의 강점을 찾다 |
| 현장 기록 | `커피챗 노트: 만난 분` / `행사 이름 후기: 핵심 메시지` | 채널콘 2024 후기: 'CX가 주인공이 되는 세상'이 온다 |
| 책 읽기 (한 권) | `핵심 메시지 <책 제목>` | 자율과 책임 문화의 교과서 <규칙 없음> |
| 책 읽기 (월간) | `YY년 M월의 독서: 한 줄 요약` | 23년 8월의 독서: B2B 기업도 브랜딩이 필요할까? |
| 좋아하는 것들 | `작품 이름: 핵심 메시지` | 헌터헌터: 목표를 잊을 정도로 즐거운 과정의 이야기 |

## 썸네일

커버 이미지(`cover`)가 없는 글은 빌드할 때 **분류 색상 + 제목 + 라마 심볼**로 썸네일을 자동으로 만듭니다(`/blog/글주소/thumbnail.png`, `app/blog/[slug]/thumbnail.png/route.tsx`). 글 목록 카드와 SNS 공유 이미지에 쓰입니다. 직접 만든 커버를 쓰고 싶으면 `cover`만 적으면 됩니다.
